# ביקורת 360° למוצרים דיגיטליים

אפליקציה שמריצה ביקורת מלאה על אתר, אפליקציית ווב, אפליקציית מובייל או SaaS, לפי ההיררכיה:
**תת-סוכנים ← סוכן מפקח לכל מחלקה ← סוכן מתאם ראשי ← בודק אנושי.**

## מה היא עושה
1. **איסוף ראיות פסיבי**: טוענת את עמוד הבית ועד 7 עמודים פנימיים חשובים (מחירים, הרשמה, פרטיות, נגישות…). בודקת הפניות http→https, כותרות אבטחה, robots/sitemap, עמוד 404 וקישורים שבורים. מחלצת כותרות, תגיות og, טפסים, תמונות בלי alt, סקריפטים של צד שלישי, הערות בקוד ומפתחות חשופים (מוצגים מוסתרים). אין התחברות, אין שליחת טפסים ואין סריקות.
2. **שלב 0, מיפוי**: סיכום המוצר, מה נבדק, מה חסר, וטבלת כיסוי לכל אחד מ-24 תתי-הסוכנים. תת-סוכן בלי חומר לא מופעל ומדווח "לא נבדק".
3. **שלב 1**: 24 תתי-סוכנים (TECH, UX, PERF, SEC, CONV, BIZ), כל אחד עם הצ'קליסט שלו בלבד. לכל ממצא: ראיה, ודאות, חומרה, השפעה, המלצה ומאמץ.
4. **שלב 2**: 6 מפקחים. מוחקים ממצאים בלי ראיה, מאחדים כפילויות, מתקנים חומרה, נותנים ציון 0–100 ובוחרים 3 ממצאים מובילים.
5. **שלב 3**: מתאם ראשי. מאחד בין מחלקות, מזהה דפוסים רוחביים ובונה את הדו"ח. הציון הכולל, הדירוג (חומרה גבוהה + מאמץ נמוך קודם) והניצחונות המהירים מחושבים בקוד, לא על ידי המודל.
6. **שלב 4**: רשימת אימות לכל ממצא 🟡/⚪. **הדו"ח ללקוח נפתח להורדה רק אחרי שכל הפריטים סומנו.**

הדו"ח כולל את 10 הסעיפים שבבריף ויוצא כקובץ HTML עצמאי בשתי גרסאות: פנימית (עם סעיף 10 ונספח המיפוי) וגרסה ללקוח.

## הפעלה
צריך Node 20 ומעלה ומפתח Claude API.

```bash
cd audit-app
npm install
export ANTHROPIC_API_KEY=sk-ant-...
npm start
# פותחים http://127.0.0.1:3360
```

## הגדרות (משתני סביבה)
| משתנה | ברירת מחדל | מה עושה |
|---|---|---|
| `AUDIT_MODEL` | `claude-opus-5` | המודל לכל הסוכנים |
| `AUDIT_EFFORT_SUBAGENT` | `medium` | עומק החשיבה של 24 תתי-הסוכנים |
| `AUDIT_EFFORT_SUPERVISOR` / `AUDIT_EFFORT_COORDINATOR` | `high` | עומק החשיבה של המפקחים והמתאם |
| `AUDIT_CONCURRENCY` | `6` | כמה סוכנים רצים במקביל |
| `AUDIT_MAX_PAGES` | `8` | כמה עמודים לטעון מהאתר |
| `AUDIT_MAX_HTML_CHARS` | `60000` | אורך ה-HTML הגולמי לכל עמוד. החיתוך מוצהר בחומר ולא נעשה בשקט |
| `AUDIT_DATA_DIR` | `data` | איפה נשמרות הביקורות |
| `PORT` / `HOST` | `3360` / `127.0.0.1` | כתובת השרת |

**עלות:** ביקורת מלאה היא כ-32 קריאות למודל. תיק החומרים נשלח עם prompt caching, כך שרוב הקלט אחרי הקריאה הראשונה נקרא מהמטמון. בסוף הדו"ח הפנימי מופיע סיכום השימוש בטוקנים.

## מגבלות
- ניתוח HTML סטטי לא רואה תוכן שנטען ב-JavaScript. ממצאים כאלה מסומנים 🟡 ונכנסים לרשימת האימות.
- מהירות אמיתית (Core Web Vitals) נבדקת רק אם מדביקים נתונים בשדה האנליטיקס. בלי זה PERF-A מדווח "לא נבדק".
- באפליקציית מובייל (קישור לחנות) לא מתבצע איסוף מהרשת. צריך לצרף צילומי מסך.
